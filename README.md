# АГЕРИС — пест-контроль по ХАССП: превью-черновик для агерис.рф/audit

Превью-черновик страницы [агерис.рф/audit](https://агерис.рф/audit/) с новым заголовком и фото на первом экране мобильной версии. На сайт эта версия пока не выложена: на агерис.рф/audit работает версия [`ageris-29102026-v1`](https://github.com/sokolnikovalex1975/ageris-29102026-v1).

Просмотр: https://sokolnikovalex1975.github.io/ageris-05112026-v1/

Версия `ageris-05112026-v1`.

## Что изменено

1. **Заголовок первого экрана (`<h1>`):** «Пест-контроль по ХАССП вместо разовых обработок».
2. **Подзаголовок под ним:** убран повтор про разовые обработки — теперь «Системная программа мониторинга и предотвращения. Соответствие ХАССП, ISO 22000, требованиям Роспотребнадзора.»
3. **Мобильная версия первого экрана (экраны до 768 px):** порядок блоков сверху вниз — заголовок и подзаголовок, затем hero-фото со специалистами, затем кнопки «Запросить бесплатный аудит» и «Узнать больше», затем блок «Программа пест-контроля включает» с 5 пунктами. Для телефонов подготовлен отдельный адаптивный кроп фото в WebP (`hero-mob-480.webp`, `hero-mob-768.webp`, `hero-mob-960.webp`) и резервный `hero-mob.jpg`.

Остальные блоки страницы, `<title>`, `meta description`, Open Graph, код Яндекс Метрики, UIS (CoMagic), Botfaqtor и Radist не менялись.
