# АГЕРИС — пест-контроль по ХАССП: превью нового заголовка для агерис.рф/audit

Превью страницы [агерис.рф/audit](https://агерис.рф/audit/) с новым заголовком первого экрана. На сайт эта версия пока не выложена: на агерис.рф/audit работает версия [`ageris-29102026-v1`](https://github.com/sokolnikovalex1975/ageris-29102026-v1).

Просмотр: https://sokolnikovalex1975.github.io/ageris-05112026-v1/

Версия `ageris-05112026-v1`.

## Что изменено

Только заголовок первого экрана (`<h1>`) в `index.html`. Косая черта в таблице — перенос строки.

| | Заголовок |
|---|---|
| Было | Защищаем бизнес / от вредителей / по стандартам ХАССП |
| Стало | Пест-контроль / по ХАССП для бизнеса |

- Заголовок совпадает с объявлениями: в РСЯ — «Пест-контроль по ХАССП для бизнеса», в поисковой кампании — «Пест-контроль для бизнеса по стандартам ХАССП». Он начинается с основного запроса «пест-контроль» и отличается от заголовка страницы [агерис.рф/services/pest-control/](https://агерис.рф/services/pest-control/) («Пест-контроль в Москве»), чтобы две страницы сайта не конкурировали за один запрос.
- Перенос стоит после слова «Пест-контроль», а «по ХАССП» и «для бизнеса» не разрываются (неразрывные пробелы). На экранах шириной от 360 до 1920 px заголовок занимает две строки вместо трёх, на самых узких телефонах (320 px) — три.

Подзаголовок, кнопки, остальные блоки страницы, `<title>`, описание страницы (`meta description`), Open Graph, код Яндекс Метрики, UIS (CoMagic), Botfaqtor и Radist не менялись.

Сравнить с предыдущей версией: `git diff ageris-29102026-v1 main -- index.html`.

## Выкладка на агерис.рф

Только после отдельного согласования. В шаблоне `page-audit.php` темы `ageris` меняется одна строка — та же, что в `index.html`. Остальные файлы темы, счётчики и колл-трекинг не трогаются.

## Что внутри

| Путь | Содержимое |
|---|---|
| `index.html` | HTML страницы |
| `wp-content/themes/ageris/assets/` | стили, скрипты и изображения темы; структура папок такая же, как на сайте |
| `wp-content/themes/ageris/assets/fonts/` | шрифты Literata и Montserrat (Google Fonts, лицензия OFL) |
| `wp-content/themes/ageris/assets/vendor/` | jQuery 3.3.1 и Fancybox 3.5.7 |
| `wp-content/plugins/contact-form-7/` | стили и скрипты формы заявки |
| `wp-includes/js/dist/` | служебные скрипты WordPress для формы |

Исходные JPG и PNG оставлены рядом с WebP: они могут использоваться на других страницах сайта.

## Отличия копии от страницы на сайте

1. Файлы подключаются из репозитория по относительным путям.
2. Ссылки меню и подвала ведут на страницы агерис.рф.
3. В плашке города стоит «Москва». Сервер подставляет город по IP посетителя, а копия снималась с сервера в США.
4. Вне домена агерис.рф не загружаются Яндекс Метрика, UIS (CoMagic), Botfaqtor и Radist, а формы показывают сообщение вместо отправки заявки. На агерис.рф этот код работает как на боевой странице.

Canonical и мета-теги указывают на агерис.рф/audit.
